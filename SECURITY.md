# Security Policy

## Supported Versions

We actively release security patches and bug fixes for the following versions of Reyhan Commerce:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Reyhan Commerce core team takes security seriously. If you discover a security vulnerability within Reyhan Commerce or any of its official ecosystem packages, please report it responsibly:

1. **Do NOT open a public GitHub issue** to report a security vulnerability.
2. Email the core security team at: **security@reyhan.io** or **farshid@reyhan.io**.
3. Include detailed steps to reproduce the vulnerability, sample payloads, and the affected package version.

### Response Commitment

* We will acknowledge receipt of your vulnerability report within **48 hours**.
* We will provide an initial assessment and estimated fix timeline within **7 business days**.
* Once the vulnerability is resolved, a patch release will be published on Packagist / GitHub Releases with proper credit in the release notes.
